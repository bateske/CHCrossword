# The display font: the title, the banners and the screens' headings. A
# bold slab serif in the manner of CHBlackjack's lettering, drawn for this
# game. Capitals are 11 rows tall (rows 0..10); lowercase has its x-height
# on rows 4..10 and descends to row 12. Each glyph: a line "= c" (c the
# character), then its rows, '#' set and '.' clear, all one width. Leading
# and trailing all-clear rows are trimmed by tools/assets.py, so a glyph
# need only list the rows from its first to its last set one, starting at
# the row given after the character ("= g 4": its first row is row 4).
